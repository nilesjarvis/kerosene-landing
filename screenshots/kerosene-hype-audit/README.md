# HYPE Header Watermark Audit

Captured while updating the Kerosene landing hero.

## Variants Tried

- `amber-desktop.png`: Orange mask fit the palette, but the HYPE silhouette was not recognizable enough.
- `mint-desktop.png`: Original HYPE color was clearer, but the mint block felt too separate from the orange visual system.
- `offset-desktop.png`: Most subtle, but too faint to read as intentional.
- `bleed-desktop.png`: Recognizable and large, but it intruded too far into the hero and competed with the headline.
- `strip-desktop.png`: Best balance. It keeps the HYPE shape contained to the header strip, stays subtle, and preserves headline focus.

## Selected Treatment

The live page uses the strip-contained treatment shown in `final-desktop.png` and
`final-mobile.png`.
